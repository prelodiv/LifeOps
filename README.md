# LifeOps

A personal operating system for habits, health, finances, debt tracking and career growth.

## Overview

LifeOps is a personal productivity and self-improvement platform designed to help users manage their habits, physical health, finances, debts, career goals and daily planning from a single place.

The project was created as both:

- A real-world personal management system.
- A portfolio project demonstrating full-stack development skills using .NET, SQL Server, React, Next.js, Azure and modern DevOps practices.

---

## Current Goals

- Lose weight from 100kg+ to 90kg.
- Eliminate personal debt.
- Improve English skills.
- Track gym consistency.
- Track study sessions.
- Improve career opportunities.
- Build discipline through measurable habits.
